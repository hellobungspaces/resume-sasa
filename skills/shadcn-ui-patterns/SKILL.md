# Shadcn UI Pattern Skill

## Visual Aesthetics
- **Borders & Radii**: High-precision `1px border border-border`, `rounded-xl`, subtle muted foregrounds (`text-muted-foreground`).
- **Typography Scale**:
  - `h1`: `text-3xl sm:text-4xl font-bold tracking-tight`
  - `h2`: `text-2xl font-semibold tracking-tight border-b pb-2`
  - `h3`: `text-xl font-semibold tracking-tight`
  - `body`: `text-base leading-relaxed text-muted-foreground`
- **Button Variants**: `default`, `outline`, `secondary`, `ghost`, with `:focus-visible:ring-2`.
