# Anti-Slop Human & Accessibility Gate

## Principles
1. **Readable Typography**: Base body text must be at least 15px/16px with comfortable line height (1.6 to 1.7).
2. **Accessible Contrast**: Background to foreground text contrast must pass WCAG 2.1 AA (min 4.5:1 for body text, 3:1 for large headers).
3. **Keyboard Accessibility**: All interactive elements (language switcher, theme toggle, tabs, modal buttons, copy contact buttons) must have clear `:focus-visible` outlines.
4. **Actionable Contact**: Provide one-click Copy Email, Copy Phone, direct WhatsApp Click-to-Chat, direct LinkedIn link, and direct Download/Print Resume trigger.
5. **Screen Reader Semantics**: Use proper semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`, `<figure>`, `<time>`).
