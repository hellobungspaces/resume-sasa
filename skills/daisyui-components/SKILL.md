# DaisyUI Component Skill

## Tokens & Utilities
- **Theme Variables**: `--p` (primary), `--pf` (primary focus), `--b1` (base background), `--b2` (secondary surface), `--bc` (base content/text), `--rounded-box`, `--rounded-btn`.
- **Key DaisyUI Components**:
  - `timeline`: Vertical chronological flow with connected spine and dot markers for career progression.
  - `badge`: Categorical tags (`badge-outline`, `badge-primary`, `badge-ghost`).
  - `card`: Surface container with `card-body`, clean border, and subtle padding.
  - `tabs`: Segmented control for switching views smoothly (`tabs-boxed`, `tab-active`).
  - `modal`: Accessible overlay for detailed case study / direct contact form.
