# Anti-Slop Layout & Mobile Ergonomics

## Guidelines
1. **Touch Targets**: All buttons, links, and switches must have a minimum clickable area of 44x44px.
2. **Reflow & Overflow Prevention**: Zero horizontal scrolling on standard mobile widths down to 320px.
3. **Responsive Grid**:
   - Mobile: 1 column clean vertical rhythm, sticky navigation with quick contact access.
   - Tablet: 2 column balanced layout.
   - Desktop: Refined asymmetric editorial grid with sticky sidebar profile summary and detailed timeline/case studies on the right.
4. **Print Optimization**: Dedicated `@media print` CSS so recruiters can press Ctrl+P / Cmd+P or click "Print / PDF" and get a clean, perfectly structured, black-and-white 1-page/2-page physical resume layout without web navbars or buttons!
